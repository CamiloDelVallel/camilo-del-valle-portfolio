# Camilo Del Valle Portfolio

Bilingual professional portfolio for Camilo Del Valle Ledesma, Tech Lead focused on software, business intelligence, automation, and data.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static production output is written to `dist/`. The project is configured for automatic Vite detection on Vercel.

## Content and assets

- Spanish and English content are maintained in `src/App.jsx`.
